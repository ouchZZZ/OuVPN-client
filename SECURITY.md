# Reporting a security issue

This is an experimental Android client, not a security-audited VPN service. For a suspected credential leak, traffic leak or other security issue, use **Security → Report a vulnerability** on GitHub if private reporting is available. If it is not available, contact the maintainer privately rather than posting sensitive details in a public issue.

Do not send subscription links, device IDs, WireGuard private keys, endpoint addresses or unredacted configs and logs. A useful first report includes the app version, Android version, whether the route was direct or relayed, and short steps using dummy values.
