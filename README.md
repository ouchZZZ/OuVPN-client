# ouVPN client

**Простой Android-клиент для VPN-подписок с автовыбором ноды по измеренной скорости скачивания.** Среди маршрутов от 10 Мбит/с клиент учитывает и задержку. Поддерживаются VLESS/XUDP и Hysteria 2; к своему WireGuard-серверу можно подключиться напрямую или поверх ноды из подписки.

```text
Телефон ──────────────────────────────► домашний WireGuard ─► LAN / интернет
Телефон ─► VLESS/XUDP или Hysteria 2 ─► домашний WireGuard ─► LAN / интернет
Телефон ─► VLESS/XUDP или Hysteria 2 ───────────────────────► интернет
```

> Код приложения написал ChatGPT. Это экспериментальный клиент, а не VPN-сервис и не официальный клиент Happ, WireGuard или sing-box.

## Что умеет

- **Подключиться** — сначала коротко проверить лидера по сохранённым замерам. Если он недоступен, даёт меньше 1 Мбит/с или замеров ещё нет, запускается полный отбор. Если есть результаты от 10 Мбит/с, клиент сравнивает такие маршруты по баллу `скачивание / (1 + задержка_мс / 3000)`; иначе важна только скорость скачивания. Задержка — время до первого байта через тот же маршрут, а в режиме WireGuard — через весь туннель. При активном VPN ухудшение связи не запускает проверку или переподключение. Только при переходе на Wi‑Fi или с него авторежим WireGuard сравнивает прямой маршрут и маршрут через уже известную лучшую ноду, если она есть. Остальные ноды не проверяются.
- **Выбрать вручную** — закрепить прямой маршрут или конкретную ноду. Авторежим не меняет закреплённую ноду сам.
- **Проверить VPN** — сначала HTTPS-проверка доступности (до пяти нод параллельно, до 1,5 секунды на каждую, включая запуск). Затем скорость измеряется только у ответивших, по одной ноде за раз: до 3 секунд на ноду и до 5 секунд на маршрут WireGuard. Отдача измеряется отдельно только при ручной проверке. В режиме WireGuard дополнительно проверяются прямое подключение и туннель через до пяти лучших нод. Проверка не меняет выбранный маршрут; в режиме WireGuard она может временно приостановить трафик.
- **Подписки Happ** — импорт/обновление по HTTPS, удаление из приложения, фоновое обновление примерно раз в шесть часов, когда Android позволит. При ошибке остаётся предыдущий рабочий список. Удаление не освобождает слот устройства у провайдера.
- **Приложения вне VPN** — список с поиском; отмеченные приложения используют обычную сеть. Изменения применяются при следующем подключении. Статус и кнопка отключения доступны в шторке, если разрешены уведомления.

## Быстрый старт

1. Скачай APK для ARM64 из [предварительного релиза 1.2.5](https://github.com/ouchZZZ/OuVPN-client/releases/tag/v1.2.5) или собери его по инструкции ниже. Для подключения без WireGuard нужен **Android 10+**, для режима WireGuard — **Android 8+**. Релизный APK не установится поверх debug-версии: перед её удалением сохрани исходный `.conf` и ссылки подписок отдельно.
2. Добавь подписку Happ. Поддерживаются списки ссылок VLESS/HY2, в том числе Base64, и совместимые профили из Xray JSON. Конфигурация Xray целиком не исполняется.
3. Нажми **«Подключиться»** для автовыбора или выбери ноду вручную.
4. Чтобы подключить свой WireGuard-сервер, импортируй `.conf` с одним `Peer` и `Endpoint` и включи **«Домашний WireGuard поверх подписок»**. Конфиг и результаты замеров сохраняются локально в зашифрованном виде. Если галочка снята или конфига нет, клиент использует ноду без WireGuard. Для смены режима сначала отключи VPN.

### Ограничения и данные

- Для выхода в интернет домашний WireGuard-сервер должен быть настроен как шлюз. Промежуточная нода должна пропускать UDP до его `Endpoint`. Доступность на каждой сети не гарантируется.
- Это **не** системный Always-on VPN или kill switch. При активном системном туннеле клиент не включает прямой выход вместо потерянного маршрута; при отключении VPN или завершении его процесса Android может вернуть обычную маршрутизацию.
- Подписки и кэш нод хранятся локально, в зашифрованном хранилище Android. При запросе подписки отправляется совместимый `User-Agent` Happ. С включённой регистрацией также отправляются стабильный ID **этого приложения**, модель и версия Android; провайдер может занять отдельный слот. Для замеров используется Cloudflare (`speed.cloudflare.com` и DNS-over-HTTPS в проверке через дом). В коде приложения нет собственной аналитики или сервера телеметрии.
- Подключение через ноду без WireGuard проверено на Android-устройстве. Совместимость со всеми моделями, прошивками и профилями не гарантируется.

## Сборка и тесты

Нужны JDK 17, Android SDK Platform 34, Build Tools 34.0.0, Go 1.26.10 и `python3` в PATH. Укажи `ANDROID_HOME` либо `sdk.dir` в локальном `local.properties`.

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

В PowerShell: `./gradlew.bat :app:testDebugUnitTest :app:assembleDebug`. APK: `app/build/outputs/apk/debug/app-debug.apk`.

Для интеграционных тестов укажи `SING_BOX_TEST_BINARY` с путём к desktop sing-box **1.14.4**. Эти тесты проверяют UDP через VLESS/XUDP, локальный WireGuard и конфигурацию прямого TUN. APK собирает ARM64-движок из проверенного исходного модуля sing-box с [передачей TUN-дескриптора](native/direct-tun). UDP через переданный дескриптор проверяется отдельно на Linux; это не заменяет проверку `VpnService` на Android.

**English summary:** A simple Android client for VPN subscriptions that picks a VLESS/XUDP or Hysteria 2 node by measured download speed and considers latency among routes reaching at least 10 Mbps. It can optionally connect to your own WireGuard server directly or through a subscription node. The application code was written by ChatGPT.
