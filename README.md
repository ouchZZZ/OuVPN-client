# ouVPN client

**Android-клиент для домашнего WireGuard.** Подключается напрямую, когда это удобно, или ищет рабочий путь до того же домашнего сервера через ноды VLESS/XUDP и Hysteria 2 из твоих подписок. Промежуточная нода доставляет пакеты до дома, а интернет для приложений в туннеле выходит через домашнее подключение.

```text
Телефон ──────────────────────────────► домашний WireGuard ─► LAN / интернет
Телефон ─► VLESS/XUDP или Hysteria 2 ─► домашний WireGuard ─► LAN / интернет
```

> Это личный проект, не VPN-сервис и не официальный клиент Happ, WireGuard или sing-box. **Весь код приложения написал ChatGPT.** [@ouchZZZ](https://github.com/ouchZZZ) придумал сценарий, определял поведение и проверял приложение на своём телефоне. Сторонние движки написаны своими авторами.

## Что умеет

- **Подключиться** — автоматически выбрать маршрут до дома. На Wi‑Fi сначала пробует прямой WireGuard; от 10 Мбит/с полный перебор не нужен. При смене сети проверяет текущий путь и ищет замену, если связи нет или повторный замер ниже 1 Мбит/с.
- **Выбрать вручную** — закрепить прямой маршрут или конкретную ноду. Авторежим не меняет закреплённую ноду сам.
- **Проверить VPN** — короткая проверка доступности нод (до четырёх одновременно, до 1,5 с на запрос), замеры скачивания и отдачи, затем отдельный тест через домашний WireGuard напрямую и через до пяти лучших нод. Полный тест может временно приостановить трафик и не меняет выбранный маршрут после завершения.
- **Подписки Happ** — импорт/обновление по HTTPS, удаление из приложения, фоновое обновление примерно раз в шесть часов, когда Android позволит. При ошибке остаётся предыдущий рабочий список. Удаление не освобождает слот устройства у провайдера.
- **Приложения вне VPN** — список с поиском; отмеченные приложения используют обычную сеть. Изменения применяются при следующем подключении. Статус и кнопка отключения доступны в шторке, если разрешены уведомления.

## Быстрый старт

1. Собери APK по инструкции ниже и установи на **ARM64 Android 8.0+**. Готовый публичный APK пока не распространяется.
2. Импортируй клиентский WireGuard `.conf` с одним `Peer` и `Endpoint`. Конфиг хранится только в памяти процесса; после его завершения нужен повторный импорт.
3. Для промежуточных нод добавь свою подписку Happ. Поддерживаются списки VLESS/HY2 в виде ссылок или Base64 и поддерживаемые профили из Xray JSON. Готовый Xray JSON не исполняется целиком; не все его параметры поддерживаются.
4. Нажми **«Подключиться»** или выбери ноду вручную. Проверь, что домашний сервис доступен, а внешний IP в приложении, которое не исключено из VPN, совпадает с домашним.

### Ограничения и данные

- Для выхода в интернет домашний WireGuard-сервер должен быть настроен как шлюз. Промежуточная нода должна пропускать UDP до его `Endpoint`. Доступность на каждой сети не гарантируется.
- Это **не** системный Always-on VPN или kill switch. При активном системном туннеле клиент не включает прямой выход вместо потерянного маршрута; при отключении VPN или завершении его процесса Android может вернуть обычную маршрутизацию.
- Подписки и кэш нод хранятся локально, в зашифрованном хранилище Android. При запросе подписки отправляется совместимый `User-Agent` Happ. С включённой регистрацией также отправляются стабильный ID **этого приложения**, модель и версия Android; провайдер может занять отдельный слот. Для замеров используется Cloudflare (`speed.cloudflare.com` и DNS-over-HTTPS в проверке через дом). В коде приложения нет собственной аналитики или сервера телеметрии.
- На реальном телефоне автор проверил домашние сервисы, Immich и интернет. Это не означает проверку на всех моделях, прошивках и операторах.

## Сборка и тесты

Нужны JDK 17, Android SDK Platform 34 и Build Tools 34.0.0. Укажи `ANDROID_HOME` либо `sdk.dir` в локальном `local.properties`.

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

В PowerShell: `./gradlew.bat :app:testDebugUnitTest :app:assembleDebug`. APK: `app/build/outputs/apk/debug/app-debug.apk`.

Для интеграционных тестов укажи `SING_BOX_TEST_BINARY` с путём к desktop sing-box **1.14.4**. Эти тесты используют локальные фикстуры и проверяют UDP через VLESS/XUDP и HTTP через настоящий локальный WireGuard напрямую и через VLESS; они не заменяют тест на Android. Сборка скачивает ARM64-бинарник sing-box из официального релиза и проверяет SHA-256.

**English summary:** An experimental Android client for your own home WireGuard gateway. It can connect directly or choose a VLESS/XUDP or Hysteria 2 relay from your subscriptions based on end-to-end throughput through the home tunnel. Bring your own WireGuard configuration and, optionally, a subscription. All application code was written by ChatGPT; @ouchZZZ designed and tested the workflow.
